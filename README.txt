SONIA'S ROMANTIC BIRTHDAY WEBSITE
=================================

ABOUT
-----
A multi-page romantic birthday website made for Sonia.
It uses only HTML, CSS, Bootstrap 5 and plain JavaScript.
There are no images, no React, and no backend.

PAGES
-----
index.html               Home / birthday welcome
pages/our-story.html     Our Story
pages/love-letter.html   Romantic English letter
pages/promises.html     Promises page
pages/final-surprise.html Interactive gift and confetti

FOLDERS
-------
css/style.css            All custom styling and animations
js/script.js             Reveal effects, hearts, confetti and music

HOW TO OPEN
-----------
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser.
4. Click around the navigation to explore all pages.
5. Click a music button to start/stop the generated birthday melody.
6. On the Surprise page, click the gift to reveal the final message.

CUSTOMIZE IT
------------
- In index.html, you can change "My Sonia", the intro and home-page wording.
- In pages/love-letter.html, edit the letter to add your own memories and your name.
- In pages/promises.html, edit any promises so they sound like you.
- In css/style.css, edit the colors in :root to change the whole theme.
- Music is generated by the browser's Web Audio API; it is a simple synthesized melody,
  not a recording of a commercial song.

IMPORTANT
---------
- Bootstrap is loaded from a CDN, so an internet connection is needed for Bootstrap layout.
- The music starts only after the visitor clicks a music button because browsers block
  autoplay audio by default.
- All page links are relative, so keep the folder structure unchanged.
- You can publish this folder with GitHub Pages to share it as a link.
